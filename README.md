# 외계 행군

검 하나로 외계 군단의 행진을 버티는 2D 액션이다. 화면은 공룡 게임처럼 계속 앞으로 걷고, 적은 앞에서 다가온다. 베거나 피해야 한다. 쓰러뜨릴수록 검이 강해지고, 행군이 길어질수록 적의 체력과 압박도 커진다.

## 조작

| 키 | 동작 |
| --- | --- |
| W / ↑ | 점프 |
| S / ↓ | 웅크리기 |
| A / ← | 뒤로 이동 |
| D / → | 앞으로 이동 |
| Space | 앞으로 베기 |
| Q | 대시 (A를 누른 채면 뒤로) |
| Esc | 일시정지 |
| M | 음소거 |
| Enter / R | 시작, 계속, 다시 하기 |

좁은 화면과 터치 기기에는 화면 아래 버튼이 나온다.

## 적

- **일반 병** — 창을 들고 다가온다. 점프로 넘거나 베어 쓰러뜨린다.
- **방패병** — 서서 치면 방패에 막힌다. 웅크리거나 점프해서 벤다. 방패는 막히면 조금씩 부서진다.
- **총병** — 거리를 두고 쏤다. 조준선이 낮으면 점프, 높으면 웅크리기.
- **UFO** — 피해도 그대로 플레이어에게 돌아온다. 약한 검으로 깨는 선택은 가능하지만, 검이 강해질수록 반사도 위험해진다. 대시로 통과하는 편이 안전하다.

적을 쓰러뜨리면 경험치가 쌓여 검이 `녹슨 검 → 강철 검 → 달빛 검 → 플라스마 검 → 외계핵 검` 순으로 바뀐다. 강화될 때 사거리와 피해가 늘고, 체력을 조금 회복한다.

## 실행

```bash
npm install
npm run dev
```

개발 서버는 `http://127.0.0.1:47321` 이다.

```bash
npm test
npm run build
npm run preview
```

`npm test`는 점프, 웅크리기, 이동, 대시, 방패 판정, 탄 회피, UFO 반사, 검 강화를 시뮬레이션으로 확인한다.
